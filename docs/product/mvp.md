# MVP Definition

- Phase: 8
- Last updated: 2026-09-28
- 状態: 起案中（[PROPOSED]）
- 根拠: [strategy](strategy.md), [solutions](solutions.md), [risks](risks.md)

## 1. MVP の目的

友人約 20 人に使ってもらい、Core Loop（[strategy](strategy.md)）が回るかを確かめる、最小の形。
「早く友人に触ってもらう」ことを優先する（[003](../decisions/003-user-research-approach.md)、R5）。

## 2. 確かめたいこと

| 問い | 関係する仮説・リスク | 見るもの |
|---|---|---|
| 声をかけた友人は登録するか | R2 | 声をかけた人数に対する登録者数 |
| 試聴できると、勧められた曲が聴かれるか | H4 / H1 | 投稿あたりの延べ再生回数 |
| 反応があると、投稿が続くか | H9 | 週あたりの投稿数、いいね・コメント数 |
| 暇なときに開いて、見るものがあるか | R1 | 週に 1 回以上開く人の数 |

判定: 成功基準（決定済み）の「友人 10 人が、公開 3 か月後も週 1 回以上、投稿または試聴している」。

## 3. 範囲 [PROPOSED]

### 入れる（Must）

| 機能 | 内容 | 根拠 |
|---|---|---|
| 登録・ログイン | 手間の少ない方法（方式は Phase 9） | 原則 3 |
| 招待リンク | 招待リンクから登録すると、招待した人を自動でフォローする。その人がフォローしている人をまとめてフォローできる | D1 / D2 |
| フォロー | フォロー / フォロー解除 | 決定済み |
| 投稿 | 曲名検索、Apple Music のリンク、Spotify のリンクから曲を選び、一言を付けて投稿する。候補から投稿者が選ぶ・確認する | A1〜A3 |
| 試聴 | Apple の試聴音源を再生する。出典表示と Apple Music へのリンクを付ける | B1 |
| 各自のサービスで開く | 設定で使っているサービス（Spotify / Apple Music / YouTube Music）を選ぶ。そのサービスで開くボタンを出す | C1 |
| タイムライン | フォローしている人の投稿を時系列で表示し、過去もさかのぼれる | E1 |
| いいね・コメント | いいねのみ。コメントに返信機能はなし | F |
| 延べ再生回数 | 投稿者だけが見られる | F |
| プロフィール | その人の過去の投稿一覧 | E3 |
| 自分の投稿・コメントの削除 | ― | 最低限の運営 |
| プライバシーポリシー・利用規約 | 個人情報を扱う以上、友人だけの段階でも必要 | R6 |

### 入れない（MVP の後で検討）

| 機能 | 理由 |
|---|---|
| 通知（プッシュなど） | 開発者の回答は「設定次第でいい」で、基本は暇なときに開く。実現方法が端末と技術に強く依存するため、Phase 9 の結果を見て判断する |
| 反応を確認する専用画面（E2） | MVP では、自分の投稿に付いたいいね・コメント・再生回数を投稿自体で確認できれば足りる |
| ログインなしでの閲覧 | 広げる手段として位置づけておらず、Stage 1 には不要 |
| 誰でも登録できる状態、通報・ブロック | Stage 1 は招待リンク経由の登録に限る（下記） |
| 絵文字リアクション、過去投稿の掘り起こし（E4） | 必要と分かってから足す |

### Stage 1 は招待制で始める [PROPOSED]

- MVP の間は、招待リンクからのみ登録できるようにする。
- 一般公開（誰でも登録できる状態）は、通報・ブロックを用意してから開く。
- これは [002](../decisions/002-audience-and-openness.md)（誰でも参加できる形で公開する）の変更ではなく、公開する順番の話。
- 理由: 知らない人が入らない間は、荒らし対策（R7）を後回しにでき、MVP を小さくできる。

## 4. Spotify のリンクからの投稿の実現方法 [PROPOSED]

- まずは Spotify API を使わず、キーなしで取れる曲名（oEmbed）で Apple 側を検索し、候補から投稿者が選ぶ形にする。
- アーティスト名がないため候補がぶれやすい。使ってみて選びにくければ、Spotify API（ログイン不要の方式）でアーティスト名を取る形に変える。
- 理由: 外部依存を最小にする（原則 6、R3）。
- 根拠: [曲の照合実験](../research/2026-09-28-song-matching.md)
